# 아발론 역할 배정 도우미 (웹앱)

아발론에서 역할 카드를 나눠주고 "누가 악인지, 누가 멀린인지" 서로 확인하는 절차를,
실물 손동작(주먹/엄지, 눈 감고 뜨기) 없이 **각자 폰 화면으로만 비공개 진행**하는 로컬 웹앱입니다.

- 진행자 1명이 노트북에서 서버를 켜고 "방"을 만듭니다.
- 나머지 사람들은 **같은 와이파이**에 연결된 폰 브라우저로 접속해서 이름과 방 코드만 입력하면 됩니다.
- 진행자가 "역할 배정 시작"을 누르는 순간, 각 참가자의 폰에 다음이 **동시에** 전송됩니다.
  - 본인의 역할 (카드 이미지 포함)
  - 아발론 규칙상 그 역할이 원래 알아야 하는 사람 정보
    - 악 팀(오베론 제외): 서로의 이름
    - 오베론: "팀원에게도, 팀원이 누군지도 모른다"는 안내
    - 멀린: 악으로 보이는 사람 목록 (모드레드는 제외되어 안 보임, 오베론은 포함)
    - 퍼시벌: 멀린 (+모르가나가 있으면 둘을 섞어서, 누가 멀린인지 알 수 없게)
    - 그 외 충성스런 신하/모드레드의 수하: 별도로 알아야 할 사람 정보 없음
- 정보는 "역할 조회" 버튼을 눌러서 켜고 끄는 토글 방식으로 확인합니다.
- 역할 배정이 끝나면 진행자가 더 할 일은 없습니다. 참가자들이 각자 페이스대로 확인하고 나면 바로 게임을 시작하면 됩니다.

## 실행 방법

1. 이 폴더를 진행자 노트북(또는 PC)에 둡니다. (Node.js 설치 필요: https://nodejs.org LTS 버전)
2. 터미널에서:
   ```
   npm install
   npm start
   ```
3. 터미널에 뜨는 안내대로, 이 컴퓨터의 로컬 IP를 확인합니다.
   - Mac: `ipconfig getifaddr en0` (와이파이 기준, 유선이면 en1 등)
   - Windows: `ipconfig` 실행 후 "IPv4 주소" 확인
   - 보통 `192.168.x.x` 형태입니다.
4. **진행자**는 같은 컴퓨터에서 브라우저로 `http://localhost:3000/host.html` 접속.
5. **참가자들**은 각자 폰 브라우저(같은 와이파이 연결 필수)에서
   `http://<진행자 컴퓨터의 IP>:3000/player.html` 접속.

## PC 없이, 클라우드에 올려서 쓰는 방법 (한 번만 설정하면 이후로는 PC 불필요)

매번 노트북을 챙겨서 서버를 켜는 게 번거롭다면, 이 앱을 인터넷에 올려서 계속 켜두고 그 다음부터는
아이패드/폰 브라우저로 주소만 열어서 쓰는 방법도 있습니다. 이 경우 **같은 와이파이가 아니라
각자 인터넷(와이파이 또는 데이터)에만 연결돼 있으면 됩니다.** 아래는 [Render](https://render.com)
기준 (무료 요금제 있음, 예시일 뿐 Railway·Fly.io 등도 비슷한 방식으로 가능):

1. GitHub 계정이 없다면 [github.com](https://github.com)에서 무료로 만듭니다.
2. GitHub에서 "New repository"로 새 저장소를 만들고, 이 폴더 안의 파일들을
   ("Uploading an existing file" 링크로 드래그 앤 드롭하면 git 명령어 없이도 업로드 가능)
   그대로 올립니다. (`node_modules` 폴더는 올릴 필요 없습니다 — 어차피 배포 시 자동으로 설치됩니다.)
3. [render.com](https://render.com)에 GitHub 계정으로 가입 → "New +" → "Web Service" →
   방금 만든 저장소 선택.
4. 이 프로젝트에는 `render.yaml`이 이미 포함돼 있어서 빌드/시작 명령이 자동으로 인식됩니다
   (수동 설정 시 Build Command: `npm install`, Start Command: `npm start`).
5. 배포가 끝나면 `https://프로젝트이름.onrender.com` 같은 주소가 생깁니다.
   - **진행자**: `.../host.html` 접속
   - **참가자**: `.../player.html` 접속
6. 무료 요금제는 한동안 사용이 없으면 서버가 잠들었다가, 다음 접속 때 30~60초 정도 깨어나는
   데 시간이 걸립니다. 이 텀이 거슬리면 유료 "Starter" 플랜(월 7~8천원대)으로 올리면 항상 켜져 있습니다.
7. 방 정보는 서버 메모리에만 있어서 서버가 재시작되면 사라지는데, 어차피 게임마다 새로 방을
   만드는 구조라 문제되지 않습니다.

## 진행 순서

1. 참가자들이 이름 입력 후 방 코드로 입장 → 진행자 화면에 인원 목록이 뜸
   - 진행자 화면의 방 코드 옆에 QR 코드가 함께 표시됩니다. 참가자가 이 QR을 폰 카메라로 찍으면 참가자 접속 화면이 열리면서 방 코드가 자동으로 입력돼 있어서, 코드를 직접 타이핑할 필요 없이 이름만 입력하면 됩니다. 기본은 작은 썸네일로 표시되고, 탭하면 참가자들이 스캔하기 편하도록 크게 확대된 팝업으로 뜹니다 (팝업은 닫기 버튼이나 바깥 영역 탭으로 닫힘).
2. 진행자가 인원수에 맞는 선/악 인원 구성을 확인하고, 사용할 특수 역할(멀린/퍼시벌/모드레드/모르가나/오베론/암살자)을 체크
   - 암살자도 다른 역할처럼 체크박스로 켜고 끌 수 있습니다 (기본값: 켜짐)
   - 퍼시벌을 켜려면 멀린도 켜져 있어야 함
3. "역할 배정 시작" → 각자 폰에 역할+카드 이미지+관련 정보가 동시에 전송되고, 진행자 화면의 "역할 구성" 영역 우측 상단에 "배정 완료" 뱃지가 표시됨. 이때부터 인원 목록 우측에 각자 배정된 역할이 표시될 수 있는데, 기본은 "가려짐"으로 숨겨져 있고 "인원" 옆의 "역할 보기" 버튼을 눌러야 `[선]`/`[악]` 색상과 함께 보입니다 (다시 누르면 숨겨짐, 새로 배정할 때마다 다시 가려진 상태로 시작).
4. 참가자들은 각자 페이스대로 "역할 조회" 버튼을 눌러 확인 (다시 누르면 가려짐)
5. 모두 확인했으면 바로 게임(토론/원정대 구성) 시작

## 진행자 화면 레이아웃

진행자 화면은 화면 너비에 따라 자동으로 레이아웃이 바뀝니다.

- 좁은 화면(폰 세로 모드 등, 너비 700px 미만): 접속 코드/인원 목록 → 역할 구성 순으로 위아래로 쌓임
- 넓은 화면(폰 가로 모드, 태블릿, PC 창 등, 너비 700px 이상): 좌측에 접속 코드/QR/인원 목록, 우측에 역할 구성/배정 시작 버튼이 나란히 표시됨

별도 설정 없이 화면(창) 너비만으로 자동 전환됩니다.

## 그 외 기능

- 역할 확인 화면에 카드 이미지가 함께 표시됩니다 (모든 카드 이미지는 480x750으로 크기가 통일되어 있습니다). 충성스런 신하/모드레드의 수하는 여러 장의 이미지 중 참가자마다 무작위로 한 장이 배정됩니다.
- 역할 이름 앞에 `[선]`/`[악]`이 표기되고, 선은 초록색, 악은 빨간색으로 구분됩니다.
- 같이 알아야 할 사람 이름은 뱃지 모양으로 가로로 나열됩니다 (화면 너비를 넘으면 자동 줄바꿈, 가운데 정렬).
- "📷 저장" 버튼을 누르면 내 역할 카드 이미지가 화면 전체에 뜹니다. 카드 이미지 우측 상단에 `{날짜}_{순번}` 번호가 작은 뱃지로 찍힙니다 (예: `20260814_001`) — 같은 배정에서 저장한 참가자는 모두 같은 번호가 찍혀서, 나중에 몇 번째 배정에서 누가 어떤 역할이었는지 대조할 수 있습니다. 순번은 서버가 켜져 있는 동안 계속 증가하고, 서버를 재시작하면 001부터 다시 시작합니다.
  - 뜬 이미지를 **길게 눌러서 "사진에 저장"**을 선택하면 사진첩(갤러리)에 저장됩니다. 기종/브라우저에 상관없이 항상 동작하는 방법이라 이 한 가지로만 안내합니다.
  - 카드 이미지 크기는 역할마다 알아야 할 정보량에 맞게 자동으로 정해져서, 정보가 없는 역할(충성스런 신하 등)도 빈 여백 없이 깔끔하게 나옵니다.
- 카드 이미지는 승헌님이 소장하신 정품 카드를 직접 촬영한 사진을 잘라 넣은 것입니다. 개인 소장·비상업적 용도로만 사용해 주세요.
- 1~4명은 정식 밸런스가 아닌 테스트용 구성으로 동작합니다 (혼자 동작 확인용).
- 역할 배정 후 참가자가 화면을 나가면(연결 종료) 목록에서 바로 지우지 않고, 이름을 흐리게 표시하고 "(나감)"을 붙여서 행을 그대로 유지합니다 (배정된 역할도 계속 보임). "다시 배정(초기화)"을 누르면 그 시점에 실제로 남아있는 참가자만 다시 조회해서 목록을 정리합니다.
- 닉네임 입력칸의 안내 문구는 "닉네임을 입력하세요"입니다.
- 배정 전(대기실)에는 이미 들어와 있는 사람과 같은 닉네임으로는 입장할 수 없습니다 ("이미 사용 중인 닉네임입니다" 오류 표시).
- 배정 후 나갔던 참가자가 같은 닉네임으로 재접속을 시도하면, 곧바로 들어오는 게 아니라 진행자 화면에 "재접속 승인 대기" 목록으로 뜹니다. 진행자가 **승인**하면 그 사람은 원래 배정받았던 역할(카드 이미지·관련 정보 포함)을 그대로 다시 받아서 이어서 볼 수 있고, **거절**하면 재접속이 취소되고 참가자 화면에는 거절 안내가 표시됩니다. (같은 닉네임이 아니거나 나간 적 없는 사람은 배정 후 새로 들어올 수 없습니다.)

## 업데이트된 버전인데 화면이 안 바뀌어 보일 때

새 zip을 받은 뒤에도 예전 화면 그대로 보인다면, 대부분 "새 파일이 아니라 예전 파일을 보고 있는" 문제입니다. 아래 순서대로 확인해 주세요.

1. 기존 `avalon-app-bundled` 폴더를 완전히 삭제하고, 새로 받은 zip을 새 폴더에 풀기 (덮어쓰기만 하면 옛날 파일이 남아있을 수 있음)
2. 터미널에서 서버가 켜져 있다면 `Ctrl + C`로 완전히 끄고, 새 폴더에서 다시 `npm install` → `npm start`
3. 브라우저 탭을 새로고침이 아니라 **완전히 닫았다가 새로 열어서** 다시 접속 (그래도 안 바뀌면 강력 새로고침: Windows는 `Ctrl+Shift+R`, Mac은 `Cmd+Shift+R`)

## 한계

- 같은 와이파이 내에서만 동작 (외부 인터넷 배포 아님)
- 참가자가 새로고침하면 방에서 나간 상태가 되어 재입장 필요 (역할 배정 후에는 "다시 배정"을 눌러도 참가자 목록은 유지됩니다)
- iOS Safari는 진동 API 미지원 (화면 알림은 정상 동작)
- 서버(터미널)를 끄면 방 정보가 사라짐

## 파일 구성

- `server.js` — Express + Socket.io 서버, 방/역할 배정 상태 관리
- `roles.js` — 아발론 인원별 선/악 구성, 역할 배정, 역할별 이미지 풀, "누가 무엇을 알아야 하는지" 로직
- `public/host.html` — 진행자 화면
- `public/player.html` — 참가자 화면
- `public/index.html` — 진행자/참가자 선택 화면
- `public/img/roles/` — 역할별 카드 이미지
- `render.yaml` — Render에 클라우드로 배포할 때 빌드/시작 명령을 자동 인식시키는 설정 파일 (로컬 실행에는 필요 없음)
